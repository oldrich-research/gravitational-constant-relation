# Public Proof Package — Newton's Constant Phenomenological Relation

This package contains the standalone, reproducible computational proof for the phenomenological relation

$$G = \frac{4}{3}\,\frac{\hbar c}{m_e^2}\,\alpha^{21}\,\exp\!\left(-\frac{5\alpha}{2}\right)$$

for the Newtonian constant of gravitation. It bundles two complementary evidence layers:

1. **Bounded-prior scan** (Section 3 / Appendix A of the manuscript): a 22,680-candidate Python sweep over formulas of the class $A(\hbar c/m_e^2)\alpha^n\exp(-k\alpha)$ with explicit reduced-rational prefactor prior, integer exponents $n\in\{5,\dots,40\}$, and half-integer damping $k\in\{0,\dots,10\}$. Reproducible end-to-end on a laptop in seconds.
2. **Adversarial validation evidence trail** (Section 7, AV6 row): a Julia bounded-equation-search engine that explores the wider symbolic space (>10⁹ generated expressions at $C\le 20$) at evaluation budgets $\{20,30,40\}$ with a 256-target sham-parity check. Re-running the engine from scratch is dedicated-compute work; the bundled per-cost CSV ledgers are directly auditable without re-run.

## Contents

### Bounded-prior scan (Section 3 / Appendix A)

- `canonical_bounded_prior.py`: Self-contained implementation of the declared 22,680-candidate prior and the canonical candidate-list hash.
- `constants.json`: Fixed CODATA 2022 parameter values mirrored by the canonical bounded-scan executable.
- `benchmarks.json`: Public benchmark modes used for ranking (`codata2022` and `nist2026`).
- `declared_prior.csv`: The explicit declared-rerun prior `A = {p/q : 1 <= p <= 5, 1 <= q <= 30, gcd(p,q)=1, 1/3 <= p/q <= 5}` plus the fixed `n`, `k`, and mass-anchor windows.
- `scan.py`: Standalone Python script that evaluates the canonical 22,680-candidate bounded prior, prints the candidate-list hash, and emits sorted nearest-neighbor tables for a chosen benchmark.
- `extended_99792_scan.py`: Legacy extended scan preserved for lineage only; it is explicitly not the bounded publication prior.
- `top_candidates.csv`: Bundled 5-row nearest-neighbor output for the CODATA 2022 benchmark.
- `nist2026_top_candidates.csv`: Bundled 5-row nearest-neighbor output for the April 16, 2026 NIST/Metrologia benchmark.

### Adversarial validation: AV6 bounded-equation-search engine (Section 7)

- `av6_engine/run_av6_exhaustive_c40_jl15.jl`: Canonical Julia engine source (jl15 with `alpha_family` pre-seeding decoupled from the brute-force shell cap). Implements grouped/cross-merge canonical reduction, weighted dynamic chunking, and per-target sham-parity bookkeeping.
- `av6_engine/launch_jl15.sh`: Parameterized launcher (`./launch_jl15.sh <max_cost>`) used to produce every per-cost output set under controlled threading and stop guards.
- `av6_engine/spec.json`: The bounded enumeration specification (target list, budget grid, sham seeds, evaluation constants) consumed by the engine.
- `av6_outputs/c18/`, `av6_outputs/c19/`, `av6_outputs/c20/`: Per-cost output trail at engine completion depths `C=18` (publication baseline, 2026-05-08), `C=19` (extending evidence, 2026-05-09), and `C=20` (extending evidence, 2026-05-10). Each cost directory contains:
  - `bounded_shell_stats.csv`: Per-cost shell statistics (`raw_generated`, `canonical_unique`, `kept`, `elapsed_sec`, `growth_factor`).
  - `same_target_rank_tables.csv`: Top-ranked expressions per target × evaluation budget. The `g_decode_alpha_ge` rows at budgets 30 and 40 yield the canonical `4/3 * alpha^21 * exp((-5/2)*alpha)` at rank 1 with `rel_err = 1.85e-6` invariant across `C=18,19,20`.
  - `sham_best_ledger.csv`: 256-target sham-parity ledger per evaluation budget. The `matches_or_beats_g` column gives the engine's strongest answer per sham target. At budget 40, `sham_match_or_beat = 0/256` for `C=18`; the single drift to `1/256` at `C=19` and `C=20` is a `TRASH_BROAD_GRAMMAR` pow expression at `sham_index=28` carrying no $\alpha$ dependence.
- `av6_outputs/c18/diff_ledgers_publication_verdict.md`: Frozen publication-grade KPI verdict for the `C=18` baseline (PASS publication / FAIL engine equivalence INFO / REVIEW-NEEDED discovery unchanged), generated by the project's diff-ledgers tool against the comparator engine `jl13c16` and the configured `[publication_kpi]` thresholds (`canonical_full_rank1_budget=30`, `canonical_full_rank1_max_rel_err=1.0e-4`, `sham_beats_publication_max=5`).

### Cross-cutting evidence

- `metrology_residuals.csv`: Tabular compilation of modern precision metrology measurements and their residuals / z-scores relative to the formula's predicted $G$ value ($6.6743123 \times 10^{-11}\,\mathrm{m^3\,kg^{-1}\,s^{-2}}$).
- `mechanism_gap_routes.csv`: Compact audited list of surveyed mechanism classes, expected outputs, observed outputs, and structural obstructions (machine-readable companion to Section 6 of the manuscript).
- `kalinski_rochester_capture_2026-04-23.md`: Bundled prior-art capture showing exactly what Kalinski's Rochester page contained at the time of writing, in case the upstream URL or the archive.org snapshot moves.
- `LICENSE`, `SCOPE.md`: Reuse rights and explicit statement of what the package supports vs. what it does not.
- `manifest.json`: File-level SHA-256 hashes plus the canonical candidate-list hash and benchmark summaries.

## Reproduction Instructions

### Bounded-prior scan (laptop, ~30 seconds)

```bash
python3 scan.py --benchmark codata2022 --limit 5
python3 scan.py --benchmark nist2026 --limit 5
```

The script runs the complete bounded scan space of exactly 22,680 combinations, prints the canonical candidate-list hash `37ee945afb33e5c8f4a63b9874338fb38d8cab1e8b1d2c113873a2e632ff92f2`, and emits sorted nearest-neighbor tables for the requested benchmark. For the canonical CODATA 2022 benchmark, the unique top row is the formula above at `0.0819σ`. Under the NIST 2026 benchmark mode, the same row remains rank 1 at `1.1639σ`. The bundled CSV hashes in `manifest.json` correspond to the 5-row tables generated by the commands above; using a larger `--limit` preserves the candidate-list hash and the rank-1 top row, but it changes the emitted CSV digests because more rows are written.

### AV6 bounded-equation-search engine

The bundled `av6_outputs/` ledgers (per-cost shell stats, same-target rank tables, sham ledgers) are directly auditable without re-running the engine: the canonical formula at rank 1 at budgets 30 and 40 with invariant `rel_err = 1.85e-6` across `C=18,19,20` is readable directly from `same_target_rank_tables.csv`, and the 256-target sham parity is readable directly from `sham_best_ledger.csv`.

A from-scratch re-run of the engine requires Julia 1.12+, ≈24 hardware threads, and ≥30 GB RAM at `C=20`. The published baseline is `C=18` (publication-grade PASS verdict in `av6_outputs/c18/diff_ledgers_publication_verdict.md`); `C=19` and `C=20` are extending evidence preserving the same canonical rank-1 verdict.

```bash
cd av6_engine
./launch_jl15.sh 18   # publication baseline (~4.5 hours wall on 24 threads)
./launch_jl15.sh 19   # extending evidence (~14 hours)
./launch_jl15.sh 20   # extending evidence (~28 hours)
```

The launcher is idempotent and refuses to start a second run if another `run_av6_exhaustive_c40` is already active. Per-cost outputs land in `jl15_c<max_cost>_outputs/` within the run root; the trail bundled in `av6_outputs/c18/`, `av6_outputs/c19/`, `av6_outputs/c20/` is the agent-curated copy.

## Integrity and Reuse

Every file in this package is checksummed in `manifest.json` (SHA-256). The `candidate_list_sha256` field anchors the 22,680-candidate enumeration independent of file-level checksums; any future re-implementation of `canonical_bounded_prior.py` must reproduce that hash. Reuse rights are stated in `LICENSE`; the explicit boundary between what the package supports (a reproducible numerical anomaly with an exact algebraic scaffold and a documented mechanism gap) and what it does not (a derivation of Newton's constant or a probability statement against all conceivable alternatives) is stated in `SCOPE.md`.
